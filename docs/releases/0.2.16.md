# AgentBlazor 0.2.16 Release Notes

Target package line: `0.2.16` stable.

AgentBlazor 0.2.16 is a corrective CLI analyzer patch. It supersedes `0.2.15`.

## What's Changed

- Removes the `0.2.15` behavior that reframed map-related suggestions as map-layer workflows.
- Filters UI layer applier, renderer, styling, layout, and map-layer infrastructure from workflow suggestion inputs.
- Updates the LLM prompt to focus on user/business outcomes rather than raw method verbs or UI/rendering mechanics.
- Keeps ordinary business read-only services eligible when they are not just UI layer plumbing.

## Why This Matters

Map data layer appliers and rendering classes can expose public methods, but they are usually implementation details. They should not become top AgentBlazor workflow suggestions unless they represent a clear business workflow.

The analyzer should prefer services that describe useful user outcomes, not classes that apply visual layers to a UI.

## Verify

```bash
dotnet tool update --global AgentBlazor.Cli --version 0.2.16
agentblazor --version
agentblazor analyze ./MySolution.slnx --host MyBlazorApp --scan-scope solution --output ./analysis.md
```

Expected:

- `agentblazor --version` reports `0.2.16`.
- UI layer appliers/renderers are not promoted as top workflow candidates.
- Suggestions focus on business capabilities or safe read-only domain queries.
