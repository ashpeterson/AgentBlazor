# AgentBlazor 0.2.6 Release Notes

Target package line: `0.2.6` stable.

AgentBlazor 0.2.6 is a CLI patch release focused on multi-tenant and modular solution analysis.

## CLI Analyze

- Added `agentblazor analyze --scan-scope solution`.
- `--host` still identifies the Blazor startup project used for host-shape and install-readiness checks.
- Default scan behavior remains `references`: host project plus transitive project references.
- Full-solution scan behavior includes every project in the supplied `.sln` or `.slnx`, so sibling tenant/module projects can contribute routes, services, capabilities, and candidate actions even when they are not referenced by the host project.

Example:

```bash
agentblazor analyze ./MySolution.slnx --host MyBlazorApp --scan-scope solution
```

Use this when tenant projects live as separate projects in the same solution and are loaded by convention, plugin infrastructure, or deployment composition rather than direct `ProjectReference`s from the host app.

## Verification

- Added a synthetic multi-tenant solution test proving `--scan-scope solution` discovers a sibling tenant route and service.
- Focused CLI analysis tests passed locally.
- Local CLI smoke verified the report includes the sibling tenant route `/tenant-a/dashboard` and `TenantBillingService`.

## Install

```bash
dotnet add package AgentBlazor --version 0.2.6
```

Optional packages:

```bash
dotnet add package AgentBlazor.Client --version 0.2.6
dotnet add package AgentBlazor.EntityFrameworkCore --version 0.2.6
dotnet tool install --global AgentBlazor.Cli --version 0.2.6
```
